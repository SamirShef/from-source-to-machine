# Дорожная карта конвейера

## Конвейер трансформаций

В ходе чтения книги мы шаг за шагом построим полный конвейер трансляции для Pebble.
Каждая глава посвящена отдельной фазе компилятора и добавляет к нему новый функциональный слой:

```text
  [ Исходный код Pebble (.pebble) ]
                 │
                 ▼
     ┌───────────────────────┐
     │ 1. Лексический анализ │  ──> Токены (Tokens)
     └───────────────────────┘
                 │
                 ▼
     ┌───────────────────────┐
     │ 2. Синтаксический     │  ──> AST (Abstract Syntax Tree)
     │    анализ (Парсинг)   │
     └───────────────────────┘
                 │
                 ▼
     ┌───────────────────────┐
     │ 3. Семантический      │  ──> Проверка типов, Scopes,
     │    анализ             │      таблица символов
     └───────────────────────┘
                 │
                 ▼
     ┌───────────────────────┐
     │ 4. Построение IR      │  ──> Линейный IR, Граф управления (CFG),
     │    и CFG-анализ       │      Базовые блоки (Basic Blocks)
     └───────────────────────┘
                 │
                 ▼
     ┌───────────────────────┐
     │ 5. Проход оптимизаций │  ──> DCE (Dead Code Elimination),
     │                       │      Constant Folding
     └───────────────────────┘
                 │
                 ▼
     ┌───────────────────────┐
     │ 6. Генерация кода     │  ──> Итоговый машинный код / C-бэкенд
     └───────────────────────┘

```

## Необходимый инструментарий

Для сборки и отладки проекта в ходе чтения книги вам понадобятся:

* Компилятор C++ с поддержкой стандарта C++20 (GCC 13+, Clang 11+ или MSVC 2019+).
* Система сборки CMake (версии 3.20 или новее).
* Утилита Graphviz (команда `dot`) --- она понадобится нам в главах по CFG, чтобы визуализировать графы
управления программой в виде наглядных PNG/SVG-диаграмм.

Теперь, когда карта маршрута перед глазами и инструменты подготовлены, мы готовы перейти к
архитектуре компилятора и лексическому анализу!
