# Язык программирования Pebble

Вся практическая часть книги строится вокруг разработки языка **Pebble** --- минималистичного системного
языка программирования, созданного специально как учебный полигон.

В Pebble нет перегруженного рантайма или тяжелых абстракций. С точки зрения синтаксиса
это лаконичный гибрид C и Rust: код считывается интуитивно с первого взгляда, но при этом язык
предоставляет все ключевые элементы системного программирования.

```pebble
import "math.pebble";

extern "C" fn puts(s: *char): int32;

struct Point {
    x: int32;
    y: int32;
}

fn main(): int32 {
    var pt = Point { x: 10, y: 20 }; // Выведение типа Point
    var ptr: *Point = &pt;

    var is_valid = ptr != nil; // Выведение типа bool
    if is_valid {
        puts("Point initialized!");
    }

    // Универсальный цикл for (может работать и как while)
    for var i = 0, i < 10, i += 1 {
        pt.x += 1;
    }

    return 0;
}
```

Ключевые особенности Pebble:
 *Системный фундамент и работа с памятью: Прямая работа с указателями (`*T`), наличие нулевого
указателя (`nil`) и бесшовная интеграция с C-библиотеками через `extern "C"`.

* **Строгая система типов с выведением:** Явная база типов (`int32`, `uint64`, `float32`, `char`),
поддержка суффиксов у литералов (например, `10u32` или `123i8`), базовое выведение типов для переменных
(`var`) и структурные типы (`struct`).
* **Гибкое управление потоком:** Универсальная конструкция for (заменяющая стандартный `for`, `while` и
бесконечные циклы), ветвления `if`/`else if`/`else` и тернарный оператор.
* **Глубокий семантический анализ на графах (CFG):** Проверка кода в Pebble не ограничивается сверкой типов.
Семантический анализатор строит граф управления (CFG) для оптимизаций и жесткого контроля путей выполнения:
проверки инициализации переменных, корректности `return` во всех ветках и анализа недостижимого кода.

Pebble спроектирован так, чтобы быть простым в реализации, но достаточно мощным, чтобы наглядно
продемонстрировать все этапы работы современного компилятора.
