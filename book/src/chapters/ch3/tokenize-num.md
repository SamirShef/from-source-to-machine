# Строко-числа

## Введение

Перед тем как токенизировать числа, для начала выявим правила токенизации. В Pebble числа токенизируются
по следующим правилам:

1. Числа содержат цифры из десятичной системы счисления (`123`).
2. Числа могут иметь максимум одну точку (`123.45`).
3. Дробные числа вида `0.x` (*где `x` --- набор цифр десятичной системы счисления*) можно писать как `.x`
(`.5` эквивалентен записи `0.5`).
4. В конце числа может идти суфикс (`i8`/`i16`/`i32`/`i64` для целочисленных знаковых типов,
`u8`/`u16`/`u32`/`u64` для целочисленных беззнаковых типов, `f32`/`f64` для дробных типов).
5. Дробные числа без суффиксами имеют тип `float64` (`3.14159265359`).
6. Целые числа без суффикса могут приводиться к ожидаемому типу. Если никакой тип не ожидается, то
приводится к `int32`:

```pebble
var x        = 10; // 10 выведется как тип int32
var y: uint8 = 10; // 10 выведется как тип uint8
```

## Новые токены

Литералы с суффиксами уже имеют тип и не требуют вывода, как литералы без суффикса. Поэтому в Pebble такие
литералы имеют разный тип токена. Например, литерал `123f32` имеет тип токена `TokenKind::Float32Lit`,
а литерал `42u8` имеет тип токена `TokenKind::Uint8Lit`. Но что делать, если число без суффикса? Дробные
числа без суффикса имеют тип `TokenKind::Float64Lit` (по умолчанию выводятся как `float64`). Но с целыми
числами чуть сложнее. Так как они могут менять свой тип в зависимости от контекста (как в коде выше), то
компилятор должен отличать их от остальных числовых литералов. Для этого в Pebble есть специальный тип
токена `TokenKind::IntLit`. Он ставится на числа с "плавающей длиной" --- компилятор сам выявит длину (тип)
числа из контекста.

Теперь исходя из этой информации дополним `TokenKind`:

```cpp
// include/pebble/lexer/token_kind.h

$#pragma once
$#include <cstdint>
$
$namespace pebble {
$
enum class TokenKind : std::uint8_t {
    Id, // Идентификатор

    Int8Lit,    // Литерал типа int8
    Int16Lit,   // Литерал типа int16
    Int32Lit,   // Литерал типа int32
    Int64Lit,   // Литерал типа int64
    Uint8Lit,   // Литерал типа uint8
    Uint16Lit,  // Литерал типа uint16
    Uint32Lit,  // Литерал типа uint32
    Uint64Lit,  // Литерал типа uint64
    Float32Lit, // Литерал типа float32
    Float64Lit, // Литерал типа float64
    IntLit,     // Целочисленный литерал плавающей длины

    Unknown,
    Eof
    // Остальные типы токенов будем добавлять по мере расширения грамматики
};
$
$}
```
